# Executing the Query Scripts
When setting up the database, the scripts need to be executed in the following order

1. `Vehicle.sql`
2. `Service.sql`
3. `Accounts.sql`
4. `Customer.sql`
5. `Employee.sql`
6. `Manager.sql`
7. `Appointment.sql`
8. `Sale.sql`
9. `AccidentData.sql`
10. `Damage.sql`
11. `Images.sql`
